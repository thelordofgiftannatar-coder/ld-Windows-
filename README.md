# Bill World – Windows app

1. Create a new GitHub repository (or use a separate one from the Android project).
2. Upload everything in this folder (keep the `.github` folder).
3. Open **Actions** -> **Build Windows EXE** and wait for the green check (about 3-5 min).
4. Open the finished run -> scroll to **Artifacts** -> download **BillWorld-Windows**.
5. Unzip it. Use `BillWorld-Setup.exe` to install, or `BillWorld-Portable.exe` to run without installing.

Windows may show a blue "SmartScreen" warning because the app isn't code-signed. Click **More info -> Run anyway**.
